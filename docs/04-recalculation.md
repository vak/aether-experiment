# Пересчёт с учётом конечной скорости передачи информации

## Корректная постановка задачи

Теперь мы понимаем, что классический анализ содержал скрытые предположения. Давайте переформулируем задачу **корректно**.

### Что мы реально измеряем?

В эксперименте Майкельсона-Морли мы измеряем:
- **Только события в одной точке** (в точке детектора)
- **Только двусторонние времена** (испускание + возвращение)
- **Интерференцию** двух лучей, вернувшихся в одну точку

Мы **НЕ** измеряем:
- "Момент отражения" от зеркала (это не наблюдаемая величина!)
- "Скорость света в одном направлении"
- "Время прохождения туда" отдельно от "времени обратно"

### Корректная формулировка

**Вопрос:** Зависит ли **двусторонняя скорость света** от направления?

**Это единственный физически осмысленный вопрос!**

## Теорема об изотропии двусторонней скорости света

### Постановка

Пусть:
- Система отсчёта S движется со скоростью v относительно эфира
- В этой системе установлен интерферометр с плечами длины L
- Свет проходит путь туда и обратно в разных направлениях

**Вопрос:** Одинаково ли **полное время** прохождения туда-обратно во всех направлениях?

### Классический (наивный) ответ

Как мы видели:
```
T_продольн = 2Lc/(c² - v²)
T_поперечн = 2L/√(c² - v²)
```

Они различны! Отсюда предсказание сдвига полос.

### ⚠️ ОШИБКА: Что такое L?

**Критический вопрос:** Что означает "длина плеча L"?

**Наивный ответ:** Расстояние между светоделителем и зеркалом.

**Контрвопрос:** Измеренное в какой момент времени? По каким часам?

### Проблема измерения длины движущегося стержня

Чтобы измерить длину стержня, движущегося со скоростью v:

1. Нужно **одновременно** зафиксировать положения обоих концов
2. "Одновременно" требует синхронизации часов
3. Синхронизация часов зависит от конвенции
4. **Различные конвенции дадут различные длины!**

### Длина в неподвижной системе (эфир)

Пусть L₀ - длина плеча в системе покоя эфира.

### Длина в движущейся системе (лаборатория)

**В классическом подходе:** L = L₀ (длины не зависят от движения)

**В релятивистском подходе:**
- Продольная длина: L_∥ = L₀√(1 - v²/c²) (лоренцево сокращение)
- Поперечная длина: L_⊥ = L₀

Но откуда берётся лоренцево сокращение? Из требования **самосогласованности** при конечной скорости передачи информации!

## Принцип самосогласованности

### Формулировка принципа

Если мы требуем, чтобы:
1. Скорость света не зависела от движения источника
2. Максимальная скорость передачи информации конечна
3. Физические законы не противоречили друг другу

То **длины и времена должны трансформироваться определённым образом!**

### Вывод преобразований

Пусть мы используем **изотропную** конвенцию синхронизации в движущейся системе:
```
c_туда = c_обратно = c (в движущейся системе)
```

Это **определение** одновременности в движущейся системе.

### Требование согласованности для продольного плеча

В системе эфира:
```
t_туда = L₀/(c-v)
t_обратно = L₀/(c+v)
T_полное = 2L₀c/(c²-v²)
```

В движущейся системе (с изотропной конвенцией):
```
t'_туда = t'_обратно = L'/c
T'_полное = 2L'/c
```

где L' - длина плеча в движущейся системе.

### Преобразование времени

Полное время должно трансформироваться. Если мы требуем, чтобы двусторонняя скорость света была изотропной в движущейся системе, то:

```
T'_полное = γ·T_полное  где γ = 1/√(1 - v²/c²)
```

(Это следует из преобразований Лоренца)

Тогда:
```
2L'/c = γ·2L₀c/(c²-v²) = 2L₀c/[c(c²-v²)]·c/√(c²-v²)
2L'/c = 2L₀/(c²-v²)·c/√(c²-v²) = 2L₀/√(c²-v²)·√(c²-v²)/c
```

Подождите, давайте аккуратнее:

```
γ = 1/√(1-v²/c²) = c/√(c²-v²)

T_полное = 2L₀c/(c²-v²)

T'_полное = γ·T_полное = [c/√(c²-v²)]·[2L₀c/(c²-v²)]
         = 2L₀c²/[(c²-v²)√(c²-v²)]
         = 2L₀c²/(c²-v²)^(3/2)
```

Но это не выглядит просто. Давайте подойдём иначе.

## Корректный подход: преобразования Лоренца

### Исходные предположения

1. **Постулат изотропии (в движущейся системе):** Скорость света изотропна в любой инерциальной системе отсчёта
2. **Принцип относительности:** Законы физики одинаковы во всех инерциальных системах
3. **Конечность c:** Скорость света конечна и одинакова во всех направлениях

### Преобразования Лоренца

Из этих постулатов следует (можно строго вывести):

```
x' = γ(x - vt)
t' = γ(t - vx/c²)
y' = y
z' = z

где γ = 1/√(1 - v²/c²)
```

### Следствие 1: Лоренцево сокращение длин

Стержень длины L₀, покоящийся в системе S':
```
L = L₀/γ = L₀√(1 - v²/c²)  (в системе S, движущейся относительно S')
```

Или наоборот, стержень длины L₀, покоящийся в эфире (система S):
```
L' = L₀√(1 - v²/c²)  (в движущейся системе S')
```

**Это не физическое сжатие, а следствие определения одновременности!**

### Следствие 2: Замедление времени

Часы, покоящиеся в S', идут медленнее с точки зрения S:
```
Δt = γ·Δt'
```

## Пересчёт эксперимента ММ с преобразованиями Лоренца

### Система эфира (S)

Пусть плечи интерферометра имеют длину L₀ в системе эфира (когда интерферометр покоится).

**Продольное плечо (движущийся интерферометр):**
```
Длина в системе эфира: L_∥ = L₀
Время туда-обратно: T_∥ = 2L₀c/(c²-v²) = (2L₀/c)·γ²
```

**Поперечное плечо:**
```
Длина в системе эфира: L_⊥ = L₀
Время туда-обратно: T_⊥ = 2L₀/√(c²-v²) = (2L₀/c)·γ
```

Разность времён:
```
ΔT = T_∥ - T_⊥ = (2L₀/c)(γ² - γ) = (2L₀/c)γ(γ - 1)
```

### Движущаяся система (S') - лаборатория

Теперь пересчитаем в системе лаборатории, используя преобразования Лоренца.

**Ключевой момент:** В движущейся системе длины плеч **различны**!

**Продольное плечо:**
```
L'_∥ = L₀√(1 - v²/c²) = L₀/γ  (лоренцево сокращение!)
```

**Поперечное плечо:**
```
L'_⊥ = L₀  (поперечные размеры не сокращаются)
```

### Время в движущейся системе

Время прохождения света туда-обратно в движущейся системе (с изотропной конвенцией c = const):

**Продольное:**
```
T'_∥ = 2L'_∥/c = 2(L₀/γ)/c = (2L₀/c)/γ = (2L₀/c)√(1 - v²/c²)
```

**Поперечное:**
```
T'_⊥ = 2L'_⊥/c = 2L₀/c
```

### ⚠️ КРИТИЧЕСКИЙ РЕЗУЛЬТАТ!

Разность времён в движущейся системе:
```
ΔT' = T'_∥ - T'_⊥ = (2L₀/c)√(1 - v²/c²) - 2L₀/c
    = (2L₀/c)[√(1 - v²/c²) - 1]
    = (2L₀/c)[1/γ - 1]
    = -(2L₀/c)(γ-1)/γ
```

Для малых v/c:
```
γ ≈ 1 + v²/(2c²)
1/γ ≈ 1 - v²/(2c²)
ΔT' ≈ -(2L₀/c)·v²/(2c²) = -L₀v²/c³
```

**НО!** Мы забыли про ещё один эффект!

### Релятивистское замедление времени

Время, измеряемое движущимися часами, связано с временем в системе эфира:
```
T'_измер = T/γ
```

Но это уже учтено в преобразованиях!

### Правильный учёт: что мы реально наблюдаем?

Интерферометр покоится в лаборатории. В системе лаборатории:
- Продольное плечо имеет длину L (измеренную линейкой, покоящейся в лаборатории)
- Поперечное плечо имеет ту же длину L
- **Это одна и та же линейка!**

**Ключевой вопрос:** Сохранилась ли длина линейки при ускорении лаборатории?

## Изотропия в собственной системе отсчёта

### Принцип относительности

**Утверждение:** В любой инерциальной системе отсчёта, если измерять длины **покоящимися** в этой системе линейками, и синхронизировать часы с помощью света (изотропная конвенция), то:

**Скорость света изотропна: c = const во всех направлениях**

### Следствие для эксперимента ММ

В системе отсчёта лаборатории:
- Оба плеча имеют одинаковую длину L (измеренную покоящейся линейкой)
- Скорость света одинакова во всех направлениях: c
- Время прохождения: T_∥ = T_⊥ = 2L/c

**Разность времён: ΔT = 0**

**Сдвига интерференционных полос нет!**

## Почему классический расчёт неверен?

### Смешение систем отсчёта

Классический расчёт:
1. Предполагает, что интерферометр движется в эфире (система эфира)
2. Использует скорости c±v (в системе эфира)
3. Но использует длины L, измеренные в лаборатории
4. **Смешивает величины из разных систем отсчёта!**

### Корректный анализ требует

**Либо:**
- Работать полностью в системе эфира (тогда длины сокращаются)
- Использовать преобразования Лоренца

**Либо:**
- Работать в системе лаборатории (тогда c изотропна)

**Нельзя брать скорости из одной системы, а длины из другой!**

## Финальный расчёт с учётом всех эффектов

### В системе эфира (если эфир существует)

Пусть плечи в покое имеют длину L₀.

При движении со скоростью v:
```
L_продольн = L₀√(1 - v²/c²)  (лоренцево сокращение)
L_поперечн = L₀

T_продольн = 2L_продольн·c/(c²-v²) = 2L₀√(1-v²/c²)·c/(c²-v²)
           = 2L₀c/[(c²-v²)√(1-v²/c²)]
           = 2L₀c/(c²-v²)^(3/2)·c
           = 2L₀/c · c²/(c²-v²)^(3/2)
```

Упростим:
```
T_продольн = 2L₀/c · 1/(1-v²/c²)^(3/2) = (2L₀/c)·γ³
```

Для поперечного:
```
T_поперечн = 2L₀/√(c²-v²) = (2L₀/c)·γ
```

Разность:
```
ΔT = (2L₀/c)(γ³ - γ) = (2L₀/c)γ(γ² - 1)
```

Для малых v/c:
```
γ ≈ 1 + v²/(2c²)
γ³ ≈ 1 + 3v²/(2c²)
ΔT ≈ (2L₀/c)·v²/c²
```

**Стоп!** Мы всё ещё получаем ненулевой результат!

### ⚠️ ФИНАЛЬНАЯ ТОНКОСТЬ: Что мы измеряем?

Мы измеряем интерференцию **в движущейся системе**, то есть в лаборатории!

**Вопрос:** Зависит ли интерференционная картина от системы отсчёта?

**Ответ:** Нет! Интерференционная картина - это локальное явление, она не зависит от выбора системы отсчёта.

**Но!** Разность фаз зависит от разности **собственных времён** вдоль двух путей.

### Собственное время вдоль пути света

Собственное время (proper time) вдоль мировой линии:
```
dτ² = dt² - dx²/c² - dy²/c² - dz²/c²
```

Для света: dτ = 0 (свет движется по световому конусу)!

**Собственное время вдоль пути света равно нулю!**

Поэтому нельзя говорить о "собственном времени фотона".

### Что же тогда интерферирует?

Интерферирует **фаза** волны:
```
φ = ω·t - k·r
```

где t и r измеряются в **одной системе отсчёта** в **одной точке**.

В точке детектора (одна точка пространства!) фазы двух лучей:
```
φ₁ = ω·T₁
φ₂ = ω·T₂
Δφ = ω(T₁ - T₂)
```

Где T₁ и T₂ - времена прохождения, измеренные **часами детектора**.

### В системе лаборатории (детектор покоится)

Часы детектора покоятся в лаборатории. В этой системе:
- Скорость света изотропна: c
- Длины плеч (измеренные покоящейся линейкой): L
- Времена: T₁ = T₂ = 2L/c
- **Δφ = 0!**

**Никакого сдвига полос!**

## Окончательный вывод

**Эксперимент Майкельсона-Морли не может обнаружить движение относительно эфира по следующим причинам:**

1. **Лоренцево сокращение длин** компенсирует изменение времени прохождения в продольном направлении

2. Лоренцево сокращение - это не физический эффект, а **следствие определения одновременности** при конечной скорости света

3. **В собственной системе отсчёта** наблюдателя скорость света всегда изотропна (по определению синхронизации часов)

4. Классический расчёт **смешивал** величины из разных систем отсчёта

5. Корректный учёт конечности скорости передачи информации **автоматически приводит** к отсутствию сдвига полос

**Главный вывод:**
> Отрицательный результат эксперимента ММ был **предопределён** логической необходимостью, а не свойствами эфира!
