# Три слоя: что именно утверждает этот анализ

Проект смешивал три разных уровня рассуждений, что создавало путаницу.
Этот документ разделяет их явно.

---

## Слой 1: Операциональный — что можно измерить без конвенции

### Что доступно без соглашений

**Без соглашения о синхронизации часов можно измерить:**
- **Двустороннюю** скорость света: послать сигнал и принять эхо.
  Результат: c̄ = 2L / (t_туда + t_обратно). Это наблюдаемая.
- **Интерференционную картину**: она создаётся в одной точке пространства,
  одновременность не нужна.
- **Собственное время** часов вдоль конкретной мировой линии.

**Без соглашения о синхронизации нельзя измерить:**
- **Одностороннюю** скорость света c_туда: для этого нужны синхронизированные
  часы в двух разных точках. Но синхронизация сама требует знания c_туда.
  Это и есть conventionality of simultaneity (Reichenbach, 1958).

### Что это значит для ММ

Эксперимент ММ измеряет **разность** времён прохождения в двух плечах —
через интерференционную картину в одной точке. Это наблюдаемая.

Он **не** измеряет абсолютную скорость интерферометра относительно
какой-либо выделенной системы отсчёта. Такая скорость операционально
не определена без дополнительных конвенций.

## Слой 2: Кинематический — аккуратный расчёт

### Определения (фиксируются однозначно)

- **S** — произвольная инерциальная система (будем называть её «эфир» для
  наглядности, но это любая ИСО)
- **S'** — система лаборатории, где интерферометр **покоится**
- **L** — собственная длина плеча, измеренная линейкой в S' (постоянная!)
- **v** — скорость S' относительно S

### Расчёт в S (интерферометр движется)

В S скорость света изотропна и равна c. Длины плеч наблюдаются сокращёнными:

```
L_∥^(S) = L/γ    (лоренцево сокращение вдоль движения)
L_⊥^(S) = L      (поперечные размеры не сокращаются)
```

Времена прохождения (считаем через физические события, см. lorentz_events.py):

```
T_∥^(S)  = L/γ·(c-v)⁻¹  + L/γ·(c+v)⁻¹  = (2L/c)·γ
T_⊥^(S)  = 2L/√(c²-v²)                  = (2L/c)·γ

ΔT^(S)   = 0
```

### Расчёт в S' (интерферометр покоится)

Буст лоренца переводит события из S в S'. Результат:

```
T_∥^(S') = T_∥^(S) / γ  = 2L/c
T_⊥^(S') = T_⊥^(S) / γ  = 2L/c

ΔT^(S')  = 0
```

Или напрямую: в S' скорость света изотропна (это следствие постулатов СТО
или выбора эйнштейновской синхронизации), оба плеча равны L → ΔT = 0.

### Классическая ошибка

Классический расчёт подставляет скорости из S (c±v), но длину из S' (L):

```
T_∥^(классика) = L/(c-v) + L/(c+v)  = (2L/c)·γ²   ← L вместо L/γ
T_⊥^(классика) = 2L/√(c²-v²)        = (2L/c)·γ

ΔT^(классика)  = (2L/c)·γ(γ-1) ≠ 0  ← ошибка
```

Ошибка конкретна: L вместо L/γ в первой строке.
Это смешение длины из одной системы отсчёта со скоростями из другой.

## Слой 3: Интерпретационный — СТО vs лоренц-эфир vs нарушение лоренц-инвариантности

### СТО

Нет выделенной системы отсчёта. Все ИСО равноправны.
Лоренцево сокращение — кинематический эффект, следствие преобразований Лоренца.
Результат ММ: ΔT = 0, согласуется.

### Лоренц-эфирная интерпретация

Существует выделенная система эфира S. Лоренцево сокращение — динамический
эффект взаимодействия материи с эфиром. Но все наблюдаемые (включая ΔT)
совпадают со СТО, потому что физика лоренц-инвариантна.

Эти две интерпретации **эмпирически неразличимы** на стандартных тестах.
Это нормальный факт, давно известный (Bell, 1976; Brown, 2005).

### Нарушение лоренц-инвариантности

Ряд теорий квантовой гравитации допускает слабое нарушение лоренц-симметрии.
Такое нарушение дало бы ненулевой ΔT (или его угловую зависимость).

Современные ММ-подобные эксперименты (оптические резонаторы, сравнение
частот при вращении Земли) ставят верхние границы на параметры нарушения:
δc/c < 10⁻¹⁵ (Müller et al., 2003; Herrmann et al., 2009).

**Эти эксперименты содержательны.** Нулевой результат в рамках СТО не делает
их «ритуалом» — они тестируют, выполняется ли лоренц-инвариантность
на данном уровне точности.
