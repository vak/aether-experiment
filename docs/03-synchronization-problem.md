# Проблема синхронизации часов и конвенциональность одновременности

## Фундаментальный вопрос

Прежде чем анализировать ММ-эксперимент, зафиксируем реальное ограничение: можно ли вообще
измерить скорость света в **одном направлении**?

> **Как синхронизировать часы в разных точках пространства, если максимальная скорость передачи
> информации конечна?**

Это не технический, а фундаментальный эпистемологический вопрос.

## Попытка синхронизации методом Эйнштейна

### Описание процедуры

1. Помещаем часы в точку A и в точку B, разделённые расстоянием L
2. В момент времени t₀ (по часам A) посылаем световой сигнал из A в B
3. Сигнал достигает B в момент t₁ (по часам B)
4. Сигнал отражается и возвращается в A в момент t₂ (по часам A)

### Вопрос: когда синхронизировать часы B?

**Интуитивный ответ:** "В середине пути", то есть установить часы B на время:
```
t_B = t₀ + (t₂ - t₀)/2
```

### ⚠️ Скрытое предположение

**Вопрос:** Почему "в середине пути"?

**Предположение:** Скорость света одинакова в обоих направлениях:
```
c_туда = c_обратно = c
```

**Но если мы движемся в эфире:**
```
c_туда = c - v
c_обратно = c + v
```

Тогда "середина пути" по времени — не середина пути по пространству, и синхронизация
эйнштейновским методом предполагает изотропию, которую ещё нужно обосновать.

### Порочный круг

**Чтобы синхронизировать часы, нужно знать скорость света в каждом направлении.**

**Но чтобы измерить скорость света в одном направлении, нужны синхронизированные часы в двух точках.**

```
Синхронизация → требует знания c_туда и c_обратно
Измерение c_туда → требует синхронизированных часов
```

**Из этого круга нет выхода.**

## Что мы можем измерить на самом деле?

### Только двустороннюю скорость света

Без предварительной синхронизации часов мы можем измерить только:
```
c_двусторонняя = 2L/(t₂ - t₀)
```

Это **средняя скорость** туда и обратно — измеренная одними часами в одной точке.

### Мы НЕ можем измерить

- Скорость света в одном направлении (c_туда)
- Скорость света в обратном направлении (c_обратно)

**Без дополнительного соглашения (конвенции).**

## Конвенциональность одновременности

### Определение Эйнштейна

Эйнштейн предложил **конвенцию**:
> Мы **определяем** одновременность так, что скорость света одинакова во всех направлениях.

Это не экспериментальный факт, а **определение**.

### Параметр Рейхенбаха ε

Можно выбрать и другую конвенцию (Reichenbach 1958):
```
c_туда = c/(1 + ε)
c_обратно = c/(1 - ε)
```

где ε выбирается произвольно (|ε| < 1). При этом двусторонняя скорость остаётся c:
```
c_дв = 2·[c/(1+ε)]·[c/(1-ε)] / ([c/(1+ε)] + [c/(1-ε)]) = c
```

Никакой эксперимент на двусторонней скорости **не может различить** эти конвенции.
Именно это обсуждает Стэнфордская энциклопедия философии в разделе о
"conventionality of simultaneity".

## Почему это не применяется напрямую к ММ-эксперименту

**Здесь нужно сделать важную остановку.**

Весь аргумент выше — про невозможность измерить одностороннюю скорость — применим к
экспериментам, в которых свет идёт из точки A в удалённую точку B, и мы пытаемся зафиксировать
момент прибытия удалёнными часами.

**Интерферометр Майкельсона работает иначе.**

Оба луча — продольный и поперечный — **начинаются и заканчиваются в одной точке**:
светоделителе. Интерференционная картина считывается **локально**, одним наблюдателем,
без удалённых часов. Это сравнение двух **круговых** (round-trip) времён:

```
T_∥ = (время туда к продольному зеркалу) + (время обратно)
T_⊥ = (время туда к поперечному зеркалу) + (время обратно)
```

Оба — локально наблюдаемые величины. Синхронизация удалённых часов здесь не нужна.

**Именно поэтому ММ — это разумная конструкция**: Майкельсон использовал
два луча, возвращающихся обратно, чтобы обойти невозможность однонаправленного измерения.

## Что классический расчёт ММ действительно делает

Классический расчёт в системе эфира:

```
T_∥ = L/(c-v) + L/(c+v) = (2L/c)·γ²
T_⊥ = 2L/√(c²-v²)       = (2L/c)·γ
```

Это **внутренне согласованный** расчёт в рамках ньютоновской механики с эфиром.
Он не требует удалённой синхронизации — он просто подставляет L и скорости c±v
в формулы круговых времён. Результат: T_∥ ≠ T_⊥, предсказанный сдвиг ≈ 0.44 полосы.

### Где реальная ошибка

Сравним формулы:

| | T_∥ | T_⊥ |
|---|---|---|
| **Классика** | (2L/c)·γ² | (2L/c)·γ |
| **Корректно** | (2L/c)·γ | (2L/c)·γ |

Разница — в одном месте: продольная длина плеча.

Классический расчёт использует L — **собственную** длину плеча (как её измеряют в лаборатории).
Но в системе эфира движущееся плечо **лоренцово сокращено**: L_∥ = L/γ.

Подставляем:
```
T_∥^(корр) = (L/γ)/(c-v) + (L/γ)/(c+v) = (2L/c)·γ = T_⊥

ΔT = 0
```

Это единственная содержательная ошибка классического анализа:
**использование L вместо L/γ при расчёте в системе эфира**.

## Итог этого раздела

| Вопрос | Ответ |
|---|---|
| Можно ли измерить одностороннюю скорость света? | Нет, без конвенции синхронизации |
| Требует ли ММ удалённых синхронизированных часов? | **Нет** — это round-trip измерение |
| Почему классический расчёт ошибается? | Использует L вместо L/γ в системе эфира |
| Почему ΔT = 0? | Лоренцево сокращение компенсирует анизотропию c±v |

Конвенциональность скорости света и проблема синхронизации — реальные и важные
физические темы. Но они объясняют, почему нельзя **поставить эксперимент на
одностороннюю скорость**, а не почему ММ даёт нулевой результат.
Null-результат ММ объясняет лоренцево сокращение — и только оно.
