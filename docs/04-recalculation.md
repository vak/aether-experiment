# Пересчёт с учётом конечной скорости передачи информации

## Определения

Прежде чем считать, зафиксируем обозначения **однозначно**:

- **L** — собственная длина каждого плеча интерферометра (измеренная покоящейся вместе с интерферометром линейкой). Оба плеча изготовлены одинаково, поэтому в собственной системе L_∥ = L_⊥ = L.
- **v** — скорость лаборатории относительно эфира (если эфир существует).
- **c** — скорость света в вакууме (двусторонняя, измеренная).
- **γ** = 1/√(1 − v²/c²) — лоренц-фактор.

**Две системы отсчёта:**
- **S_lab** — система лаборатории (интерферометр покоится).
- **S_aether** — система эфира (интерферометр движется со скоростью v).

---

## Расчёт 1: В системе лаборатории (S_lab)

### Что известно

Интерферометр **покоится** в S_lab. По принципу относительности:

1. Законы физики в S_lab те же, что и в любой другой инерциальной СО
2. Скорость света, измеренная с использованием стандартной (эйнштейновской) синхронизации, **изотропна и равна c**
3. Оба плеча имеют одну и ту же собственную длину L

### Расчёт

**Продольное плечо:**
```
T_∥ = 2L/c
```

**Поперечное плечо:**
```
T_⊥ = 2L/c
```

**Разность:**
```
ΔT = T_∥ − T_⊥ = 0
```

### Комментарий

Это **не трюк** и не зашитый ответ. Это прямое следствие принципа относительности: в собственной СО интерферометра нет выделенного направления, скорость света изотропна, плечи одинаковы.

Но это может показаться слишком быстрым. Давайте проверим тот же результат **из системы эфира**, где скорость света анизотропна и длины сокращаются. Если обе системы дают одинаковый ответ — мы на правильном пути.

---

## Расчёт 2: В системе эфира (S_aether) — проверка

### Что известно

В S_aether интерферометр движется со скоростью v вправо. Скорость света в эфире изотропна и равна c. Но длины плеч, измеренные в S_aether, **не равны** собственным длинам.

### Лоренцево сокращение

Плечо, покоящееся в S_lab, наблюдается из S_aether как сокращённое **вдоль направления движения**:

```
L_∥^(aether) = L/γ = L·√(1 − v²/c²)
L_⊥^(aether) = L                         (поперечные размеры не сокращаются)
```

**Важно:** L — собственная длина (в лаборатории). В эфире продольное плечо **короче**.

### Время прохождения: продольное плечо

Свет идёт вдоль движения интерферометра.

**Туда** (свет догоняет удаляющееся зеркало):
```
t_→ = L_∥^(aether) / (c − v) = (L/γ) / (c − v)
```

**Обратно** (свет идёт навстречу приближающемуся светоделителю):
```
t_← = L_∥^(aether) / (c + v) = (L/γ) / (c + v)
```

**Полное время:**
```
T_∥^(aether) = t_→ + t_← = (L/γ) · [1/(c−v) + 1/(c+v)]
             = (L/γ) · 2c/(c²−v²)
             = 2Lc / [γ(c²−v²)]
```

Упрощаем. Заметим, что c²−v² = c²(1−v²/c²) и γ = 1/√(1−v²/c²):
```
γ · (1 − v²/c²) = √(1 − v²/c²)
```

Поэтому:
```
γ(c²−v²) = γ · c² · (1−v²/c²) = c² · √(1−v²/c²) = c²/γ
```

Итого:
```
T_∥^(aether) = 2Lc / (c²/γ) = (2L/c) · γ
```

### Время прохождения: поперечное плечо

Свет идёт перпендикулярно движению. За время t свет проходит путь ct, а зеркало смещается на vt. По теореме Пифагора:

```
(ct)² = L² + (vt)²
t² = L² / (c²−v²)
t = L / √(c²−v²)
```

Полное время (туда и обратно):
```
T_⊥^(aether) = 2L / √(c²−v²) = (2L/c) / √(1−v²/c²) = (2L/c) · γ
```

### Сравнение

```
T_∥^(aether) = (2L/c) · γ
T_⊥^(aether) = (2L/c) · γ

ΔT^(aether)  = 0
```

**Времена равны!** Лоренцево сокращение продольного плеча **точно компенсирует** анизотропию скорости света.

### Перевод в лабораторное время

Координатное время в S_aether связано с собственным временем часов детектора (покоящегося в S_lab) соотношением:

```
T_lab = T^(aether) / γ
```

Для обоих плеч:
```
T_∥^(lab) = (2L/c)·γ / γ = 2L/c
T_⊥^(lab) = (2L/c)·γ / γ = 2L/c
```

Результат совпадает с расчётом 1. Самосогласованность подтверждена.

## Что было неправильно в классическом расчёте?

### Классический расчёт (напоминание)

Классический анализ ММ использует:
```
T_∥ = 2Lc/(c²−v²) = (2L/c) · γ²
T_⊥ = 2L/√(c²−v²) = (2L/c) · γ
ΔT = (2L/c) · γ(γ−1) ≠ 0
```

### Ошибка: неучёт лоренцева сокращения

Классический расчёт берёт длину продольного плеча в S_aether равной L (собственной длине). Но если интерферометр движется, то в S_aether его продольный размер равен **L/γ**, а не L!

```
Классика:       L_∥^(aether) = L       → T_∥ = (2L/c)·γ²
С сокращением:  L_∥^(aether) = L/γ     → T_∥ = (2L/c)·γ
```

Разница между γ² и γ — это и есть тот ненулевой сдвиг, который ожидали Майкельсон и Морли.

### Смешение систем отсчёта

Можно сформулировать ту же ошибку иначе: классический расчёт **берёт скорости из системы эфира** (c±v), но **длины из системы лаборатории** (L). Нельзя подставлять в одну формулу величины из разных систем отсчёта.

Корректно — **либо:**
- Всё в S_aether: скорости c±v, длина L/γ → получаем ΔT = 0
- Всё в S_lab: скорость c (изотропна), длина L → получаем ΔT = 0

## Откуда берётся лоренцево сокращение?

### Это не ad hoc гипотеза

Лоренц и Фицджеральд в 1890-х предложили сокращение как **специальную гипотезу** для спасения эфира. Это выглядело искусственно.

Но лоренцево сокращение — это **неизбежное следствие** двух фактов:
1. Скорость света конечна и является максимальной скоростью передачи взаимодействий
2. Законы физики одинаковы во всех инерциальных СО (принцип относительности)

Из этих двух фактов математически следуют преобразования Лоренца, а из них — сокращение длин. Это не подгонка, а логическая необходимость.

### Связь с синхронизацией часов

Лоренцево сокращение — это **кинематический эффект**, связанный с определением одновременности:

- "Длина движущегося стержня" = расстояние между **одновременными** положениями его концов
- "Одновременность" зависит от синхронизации часов
- Синхронизация часов зависит от конечной скорости света

Поэтому лоренцево сокращение — не "физическое сжатие", а следствие того, что понятие "длина движущегося объекта" **определяется через одновременность**, которая относительна.

## Что показывает и что НЕ показывает этот анализ

### Показывает:

1. **Классический расчёт ММ содержит ошибку** — смешение величин из разных СО
2. **Корректный расчёт** (в любой СО) даёт нулевой сдвиг полос
3. **Лоренцево сокращение** — не подгонка, а следствие конечности скорости света
4. Результат самосогласован: расчёты в S_lab и S_aether дают одинаковый ответ

### НЕ показывает:

1. ~~Что эксперимент ММ "бесполезен"~~ — современные версии ММ тестируют лоренц-инвариантность с точностью 10⁻¹⁵ и дают содержательные ограничения на параметры нарушения лоренц-инвариантности
2. ~~Что эфир существует~~ — анализ работает одинаково с эфиром и без него
3. ~~Что СТО "очевидна"~~ — для вывода преобразований Лоренца нужны нетривиальные постулаты

### Важное уточнение

Современные эксперименты типа ММ (Brillet & Hall 1979, Müller et al. 2003, Herrmann et al. 2009) **не** "логически предопределены к нулевому результату". Они тестируют, выполняется ли лоренц-инвариантность с заданной точностью. Если бы лоренц-инвариантность нарушалась (что допускают некоторые теории квантовой гравитации), эти эксперименты могли бы это обнаружить.

Наш анализ показывает только, что **в рамках СТО** (или любой лоренц-инвариантной теории) сдвиг полос равен нулю. Это не делает эксперименты бессмысленными — они проверяют, верна ли СТО.
