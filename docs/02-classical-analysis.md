# Классический анализ эксперимента Майкельсона-Морли

## Схема эксперимента

Интерферометр Майкельсона состоит из:
- Источника света
- Полупрозрачного зеркала (светоделителя) в точке O
- Двух зеркал на расстояниях L₁ и L₂ от светоделителя
- Детектора интерференционной картины

```
         M₁
          |
          | L₁ (продольное плечо)
          |
    L₂----O------>  v (направление движения в эфире)
          |
          M₂

M₁, M₂ - зеркала
O - светоделитель
v - скорость движения относительно эфира
```

Для простоты будем считать L₁ = L₂ = L.

## Классический расчёт: продольное плечо

### Предположения классического подхода

1. Земля движется со скоростью **v** относительно эфира
2. Свет распространяется в эфире со скоростью **c**
3. **КРИТИЧЕСКИ ВАЖНО:** Существует единое "абсолютное время" t

### Путь туда (от O к M₁)

Пока свет проходит расстояние L до зеркала M₁:
- Зеркало M₁ движется вперёд со скоростью v
- Свету нужно "догнать" зеркало

**Время движения туда:**
```
Расстояние, которое проходит свет: c·t₁
Расстояние, на которое сместилось зеркало: v·t₁
Условие встречи: c·t₁ = L + v·t₁

t₁ = L/(c - v)
```

### Путь обратно (от M₁ к O)

Теперь зеркало M₁ и светоделитель движутся навстречу свету:

**Время движения обратно:**
```
c·t₂ = L - v·t₂
t₂ = L/(c + v)
```

### Полное время для продольного плеча

```
T_продольн = t₁ + t₂ = L/(c-v) + L/(c+v) = L·(c+v + c-v)/((c-v)(c+v))

T_продольн = 2Lc/(c² - v²) = (2L/c)/(1 - v²/c²) = (2L/c)·γ²
```

где γ² = 1/(1 - v²/c²)

## ⚠️ КРИТИЧЕСКИЙ МОМЕНТ #1: "Мгновенные часы"

**Вопрос:** Кто измеряет времена t₁ и t₂?

**Классический ответ (неявный):**
- "Время t₁" - это "момент, когда свет достиг зеркала M₁"
- "Время t₂" - это "момент, когда свет вернулся к O"

**Проблема:**
- Наблюдатель находится в точке O
- Как он узнает, что свет достиг M₁ в "момент времени t₁"?
- **Только когда свет вернётся!**

**Скрытое предположение:**
Мы неявно используем понятие "абсолютного времени", которое "течёт одинаково" во всех точках пространства, и можем "мгновенно" определить, что события в O и M₁ произошли "одновременно".

## Классический расчёт: поперечное плечо

### Путь к зеркалу M₂ и обратно

Свет движется перпендикулярно направлению движения в эфире.

За время t пока свет идёт до зеркала:
- Свет проходит путь c·t
- Зеркало смещается на v·t
- По теореме Пифагора: (c·t)² = L² + (v·t)²

```
c²·t² = L² + v²·t²
t² = L²/(c² - v²)
t = L/√(c² - v²) = (L/c)/√(1 - v²/c²) = (L/c)·γ
```

### Полное время для поперечного плеча

```
T_поперечн = 2t = (2L/c)·γ
```

где γ = 1/√(1 - v²/c²)

## ⚠️ КРИТИЧЕСКИЙ МОМЕНТ #2: Что значит "перпендикулярно"?

**Вопрос:** Что означает, что зеркало M₂ находится "перпендикулярно" направлению движения?

**Классический ответ:**
- В некий "момент времени t₀" координаты M₂ перпендикулярны скорости

**Проблема:**
- "Момент времени t₀" - это момент по каким часам?
- По часам в точке O?
- По часам в точке M₂?
- Как мы синхронизировали эти часы?

**Скрытое предположение:**
Снова используется абсолютная одновременность!

## Разность времён и сдвиг интерференционной картины

### Разность времён

```
ΔT = T_продольн - T_поперечн = (2L/c)·γ² - (2L/c)·γ = (2L/c)·γ·(γ - 1)
```

Для малых v/c:
```
γ ≈ 1 + v²/(2c²)
γ² ≈ 1 + v²/c²

ΔT ≈ (2L/c)·(v²/c² + v²/(2c²)) ≈ (2L/c)·(v²/c²)·(3/2)
```

Упрощённо:
```
ΔT ≈ Lv²/c³
```

### Разность хода

```
Δ = c·ΔT ≈ Lv²/c²
```

### Ожидаемый сдвиг полос

При повороте интерферометра на 90°:
```
δ = 2Δ/λ ≈ 2Lv²/(c²λ)
```

Для эксперимента Майкельсона-Морли:
- L ≈ 11 м (с учётом многократного отражения)
- v ≈ 30 км/с (орбитальная скорость Земли)
- λ ≈ 500 нм

```
δ ≈ 2·11·(30000)²/((3·10⁸)²·500·10⁻⁹) ≈ 0.4 полосы
```

**Ожидалось:** сдвиг ≈ 0.4 интерференционной полосы
**Наблюдалось:** сдвиг < 0.01 полосы (в пределах погрешности измерений)

## Сводка скрытых предположений

При выводе формул мы использовали:

1. **Абсолютное время:** Понятие "момент времени t" имеет смысл одновременно во всех точках пространства

2. **Мгновенная синхронизация:** Мы можем определить, что события в разных точках пространства произошли "одновременно"

3. **Абсолютное пространство:** Понятие "расстояние L" не зависит от движения

4. **Абсолютная одновременность:** События "свет покинул O" и "зеркало находится на расстоянии L" происходят "одновременно" в абсолютном смысле

5. **Независимость измерения от процесса синхронизации:** Мы можем измерить время прохождения света, не учитывая, что для синхронизации часов тоже нужен свет

## ⚠️ ГЛАВНАЯ ПРОБЛЕМА

**Все эти предположения нарушают фундаментальный принцип:**
> При конечной скорости передачи информации не существует способа мгновенно определить "одновременность" событий в разных точках пространства.

**Вопрос:** Как мы можем вычислить времена t₁ и t₂ по отдельности, если единственное, что мы реально наблюдаем - это момент возвращения света в точку O?

**Ответ классической физики:** Мы используем абсолютное время и абсолютное пространство.

**Проблема:** Это противоречит нашему постулату о конечности скорости передачи информации!
