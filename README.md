# Критический анализ эксперимента Майкельсона-Морли

## Главный тезис

> **Классический анализ эксперимента Майкельсона-Морли содержит неявное предположение: он использует собственную длину плеча L при расчёте в системе эфира, тогда как должен использовать сокращённую длину L/γ. С учётом лоренцева сокращения предсказанный сдвиг полос обращается в ноль.**

Это наблюдение не ново — по сути, именно так Лоренц и Фицджеральд объясняли нулевой результат ММ ещё в 1890-х. Мы показываем, что лоренцево сокращение — не ad hoc гипотеза, а неизбежное следствие конечности скорости передачи информации.

**Важно:** Современные ММ-эксперименты (точность 10⁻¹⁵ и выше) остаются содержательными — они тестируют лоренц-инвариантность и ограничивают параметры её возможного нарушения.

## Ключевые результаты

### 📊 Численные результаты

**Классический расчёт (ошибочный):**
```
Предсказание: δ ≈ 0.44 интерференционной полосы
Наблюдение:   δ < 0.01 полосы
→ НЕ СОГЛАСУЕТСЯ
```

**Релятивистский расчёт (корректный):**
```
В системе лаборатории: T_∥ = T_⊥ = 2L/c (точно!)
Предсказание: δ = 0 (математически точный нуль)
Наблюдение:   δ < 0.01 полосы
→ СОГЛАСУЕТСЯ
```

### 🔍 Три порочных круга классического анализа

1. **Синхронизация часов** → требует знания скорости света → требует синхронизированных часов
2. **Вычисление времён** → требует знания моментов отражения → требует синхронизации → это то, что измеряем!
3. **Измерение длины** → требует одновременности → требует синхронизации → зависит от конвенции

## Основные выводы

### 1. В чём ошибка классического расчёта?

**Конкретная ошибка:** классический расчёт использует скорости c±v (из системы эфира) и длину L (собственную, из системы лаборатории) в одной формуле. Это смешение величин из разных систем отсчёта.

**Корректно:** в системе эфира продольное плечо сокращено до L/γ, что компенсирует анизотропию скорости света.

### 2. Почему сдвиг полос равен нулю?

**В системе лаборатории:**
- Скорость света **изотропна** (по определению синхронизации часов!)
- Оба плеча имеют одинаковую **собственную длину** L
- Времена прохождения **идентичны**: T_∥ = T_⊥ = 2L/c
- **Разность времён = 0** → **сдвиг полос = 0**

**В системе эфира (с лоренцевым сокращением):**
- Продольное плечо сокращается: L_∥ = L/γ
- Поперечное плечо не сокращается: L_⊥ = L
- Эффекты **компенсируются**: T_∥ = T_⊥ = (2L/c)·γ
- **Разность времён = 0** → **сдвиг полос = 0**

### 3. Что это означает?

**В рамках лоренц-инвариантной физики (СТО) эксперимент ММ не может:**
- Обнаружить "абсолютное движение"
- Обнаружить одностороннюю анизотропию скорости света

**Но современные ММ-эксперименты могут:**
- Тестировать лоренц-инвариантность с высокой точностью
- Ограничивать параметры нарушения лоренц-симметрии (SME)
- Проверять предсказания теорий квантовой гравитации

## Философские следствия

### О природе эфира

**Вопрос "существует ли эфир?" некорректен** в мире с конечной скоростью передачи информации.

- Эфир как "абсолютная система отсчёта" → логически необнаружим
- Эфир как "излишняя сущность" → бритва Оккама
- Квантовый вакуум → существует, но лоренц-инвариантен

### О природе СТО

**СТО можно рассматривать как логическое следствие конечности скорости информации:**

```
Конечность скорости информации
    ↓
Невозможность мгновенной синхронизации
    ↓
Конвенциональность одновременности
    ↓
Преобразования Лоренца (самосогласованность)
    ↓
Лоренцево сокращение и замедление времени
    ↓
СТО
```

### О конвенциях в физике

**Конвенциональны:**
- Односторонняя скорость света
- Одновременность удалённых событий
- Синхронизация часов

**Не конвенциональны (наблюдаемы):**
- Двусторонняя скорость света
- Интервалы между событиями
- Собственное время
- Интерференционная картина

### Для понимания физики

1. **Показывает границу** между наблюдаемыми и конвенциональными величинами
2. **Объясняет "странности" СТО** как логическую необходимость
3. **Демонстрирует важность** чёткого определения измеряемых величин

### Для педагогики

**Упрощённый подход:**
> "Эксперимент ММ показал, что эфира нет → придумали СТО"

**Более точный подход:**
> "Если скорость света конечна и одинакова во всех ИСО → длины должны сокращаться → классический расчёт ММ некорректен → нулевой результат закономерен"
